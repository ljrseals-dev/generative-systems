1. Introduction: The Crisis of Provenance and the Threat of Theft

1.1 The Uncanny Valley and the Black Box

The contemporary landscape of AI-generated audio is dominated by opaque, black-box neural models—diffusion-based vocoders, autoregressive speech synthesizers, and latent-space audio generators that produce outputs without exposing their internal reasoning or parameter states. These systems, while capable of impressive fidelity in narrow domains, suffer from a fundamental epistemological problem: their outputs cannot be verified, audited, or attributed.

This problem manifests in three critical dimensions:

First, the reproducibility crisis. Given a black-box model and an input prompt, the output is not deterministically reproducible across runs, hardware configurations, or even identical software versions. The internal state of a neural network—its weights, activations, and sampling trajectories—is effectively inaccessible to external verification.

Second, the auditability gap. When an output is generated, there is no mechanism to prove how it was generated, what parameters were used, or whether the output was manipulated post-generation. This creates a vacuum of trust that is exploited by malicious actors and, more insidiously, by competitors who can claim methodological innovations without providing evidence of independent derivation.

Third, the humanity deficit. Neural audio models, trained on vast corpora of human speech and music, often produce outputs that exhibit subtle but perceptible artifacts—spectral smearing, unnatural transients, and what is colloquially termed the "uncanny valley" of synthetic voice. These artifacts arise from the statistical nature of the models: they interpolate between training examples rather than embodying physical principles of sound production.

The Artifact Harness addresses all three dimensions. By grounding synthesis in physical acoustics (the Kelly-Lochbaum waveguide and Karplus-Strong string models), by injecting controlled stochastic variance through deterministic pseudorandom number generation, and by cryptographically hashing every element of the pipeline, we produce audio artifacts that are simultaneously humanised, reproducible, and verifiable.

1.3 The AURA-V Rejection: Why the Karplus-Strong String Fails as a Vocal Replacement

The Karplus-Strong (KS) algorithm, first described by Kevin Karplus and Alex Strong in 1983, is a simple and elegant method for synthesising plucked-string sounds. The algorithm consists of:

1. Filling a delay line (of length ) with noise.
2. Outputting the delay line's contents.
3. Filtering the output (typically with a two-point averaging filter).
4. Feeding the filtered output back into the delay line.

Mathematically, the KS algorithm implements a digital waveguide with a loop filter. The fundamental frequency of the resulting sound is , where  is the sample rate. The decay time is determined by the loop filter's gain.

The AURA-V paper (Seals & Seals, 2026) tested the KS string as a replacement for the glottal source in a formant synthesizer. The conclusion was unambiguous: the KS string is not a vocal replacement.

The reasons are both physical and perceptual:

Inharmonicity. The KS string's harmonics are not integer multiples of the fundamental. The delay-line loop introduces frequency-dependent phase delays that stretch the harmonics, producing the characteristic "stretched" sound of a plucked string. Human vocal folds, by contrast, produce harmonics that are (approximately) integer multiples of F0, with deviations of less than 1%.

Decay envelope. The KS string's amplitude decays exponentially over time, with a decay rate determined by the loop filter. Sustained phonation requires a constant or slowly-varying amplitude; the KS string cannot sustain a note indefinitely.

Excitation mechanism. The KS string is excited by a noise burst; the vocal folds are excited by a quasi-periodic glottal pulse train. The spectral characteristics of these excitations are fundamentally different.

Formant structure. The KS string's spectral envelope is determined by the loop filter, which is typically a simple lowpass. Human speech has multiple resonant peaks (formants) that are determined by the vocal tract geometry. The KS string cannot produce these structures on its own.

However, the AURA-V paper did not conclude that the KS string is useless for vocal synthesis. Instead, it proposed a reconceptualization: the KS string as a timbre slot.

A timbre slot is a source signal whose spectral and temporal characteristics are well-defined but not necessarily vocal. By passing this source through a vocal-tract filter (the Kelly-Lochbaum waveguide), we can impose vocal formants onto a non-vocal source, producing a hybrid instrument that is neither purely string nor purely voice. This is the talk-box effect, famously used by Peter Frampton, Roger Troutman, and Daft Punk.

The key insight is that the KS string's inharmonicity and decay characteristics, while disqualifying it as a vocal replacement, become features when used as a timbre slot. The resulting sound is perceptually rich, with the harmonic complexity of a string combined with the formant structure of a voice.

2.1 The Kelly-Lochbaum Scattering Equations

The Kelly-Lochbaum (KL) model, introduced by John Kelly and C. Lochbaum at Bell Labs in 1962, is a discrete-time digital waveguide model of the human vocal tract. The model represents the vocal tract as a series of cylindrical sections of varying cross-sectional area, with forward- and backward-travelling pressure waves propagating between sections.

p(x,t) = p^+(t - x/c) + p^-(t + x/c)

class SFC32:
    def __init__(self, seed):
        self.a, self.b, self.c, self.d = seed
        
    def next(self):
        t = (self.a + self.b) & 0xFFFFFFFF
        self.a = self.b ^ (self.b >> 9)
        self.b = (self.c + (self.c << 3)) & 0xFFFFFFFF
        self.c = ((self.c << 21) | (self.c >> 11)) & 0xFFFFFFFF
        self.d = (self.d + 1) & 0xFFFFFFFF
        t = (t + self.d) & 0xFFFFFFFF
        self.c = (self.c + t) & 0xFFFFFFFF
        return t / 0xFFFFFFFF

1. Methodology: The Artifact Harness and Boy-Scouts-Agent-Audit

3.1 The Artifact Harness Pipeline

The Artifact Harness is a five-stage pipeline for generating, humanising, and auditing synthetic audio artifacts:

┌─────────┐    ┌──────────────┐    ┌─────────────────┐    ┌───────────┐    ┌─────────────┐
│ Source  │───▶│ Humanisation │───▶│ Placement       │───▶│ Mastering │───▶│ Provenance  │
│ (Synth) │    │ (Seeded PRNG)│    │ Diagnosis       │    │ (Limiter) │    │ (SHA-256)   │
└─────────┘    └──────────────┘    └─────────────────┘    └───────────┘    └─────────────┘


Stage 1: Source. The audio artifact is generated using the physically-based synthesis models described in Section 2. The input is a MIDI file specifying the notes, durations, and velocities. The output is a raw audio buffer at the internal sample rate (typically 48 kHz).

Stage 2: Humanisation. The raw audio is processed by the Seeded Humanisation Protocol, which injects jitter, shimmer, and drift as described in Section 2.5. The humanisation is deterministic: given the same master seed, the output is identical.

Stage 3: Placement Diagnosis. The humanised audio is analysed by the Little sQrt Placement Diagnostic, which measures the vocal-to-bed (V/B) ratio and loudness range (LRA). These metrics are used to ensure that the final mix meets broadcast standards.

Stage 4: Mastering. The audio is processed by a mastering chain (typically a limiter and a gentle EQ) to achieve the target loudness and spectral balance.

Stage 5: Provenance. The final WAV file, along with all intermediate artifacts and parameters, is hashed using SHA-256 and recorded in a structured audit log (the BSAA log).

3.2 Seeded Humanisation Protocol

The Seeded Humanisation Protocol is the core of the Artifact Harness's ability to produce organic-sounding audio from deterministic synthesis.

3.2.1 PRNG Substreams

The protocol defines three PRNG substreams, each derived from the master seed:

python
def create_substreams(master_seed):
    # Initialise splitmix64 with master seed
    state = master_seed
    
    # Generate seeds for substreams
    state, jitter_seed = splitmix64(state)
    state, shimmer_seed = splitmix64(state)
    state, drift_seed = splitmix64(state)
    
    # Create sfc32 instances
    jitter_rng = SFC32([jitter_seed, jitter_seed ^ 0xDEADBEEF, 
                        jitter_seed ^ 0xCAFEBABE, jitter_seed ^ 0x12345678])
    shimmer_rng = SFC32([shimmer_seed, shimmer_seed ^ 0xDEADBEEF,
                         shimmer_seed ^ 0xCAFEBABE, shimmer_seed ^ 0x12345678])
    drift_rng = SFC32([drift_seed, drift_seed ^ 0xDEADBEEF,
                       drift_seed ^ 0xCAFEBABE, drift_seed ^ 0x12345678])
    
    return jitter_rng, shimmer_rng, drift_rng


3.2.2 Parameter Modulation

At each sample (or control rate block), the humanisation parameters are modulated by the PRNG outputs:

python
def apply_humanisation(audio, jitter_rng, shimmer_rng, drift_rng, params):
    output = np.zeros_like(audio)
    drift_state = 0.0
    
    for n in range(len(audio)):
        # Jitter: modulate F0
        jitter = (jitter_rng.next() - 0.5) * 2 * params.jitter_amount
        f0_mod = 1.0 + jitter
        
        # Shimmer: modulate amplitude
        shimmer = (shimmer_rng.next() - 0.5) * 2 * params.shimmer_amount
        amp_mod = 1.0 + shimmer
        
        # Drift: lowpass-filtered noise
        drift_noise = (drift_rng.next() - 0.5) * 2
        drift_state = params.drift_beta * drift_state + (1 - params.drift_beta) * drift_noise
        drift_mod = 1.0 + drift_state * params.drift_amount
        
        # Apply modulations (simplified; actual implementation uses
        # interpolated delay lines for F0 modulation)
        output[n] = audio[n] * amp_mod * drift_mod
    
    return output


3.3 The Little sQrt Placement Diagnosis

The Little sQrt Placement Diagnostic is an automated system for measuring and adjusting the vocal-to-bed (V/B) ratio and loudness range (LRA) of a mix.

3.3.1 Vocal-to-Bed Ratio

The V/B ratio is the difference in loudness (in LU) between the vocal (or lead instrument) and the backing bed. For the talk-box instrument, the target V/B ratio is +15 to +20 LU, meaning the talk-box should be 15-20 LU louder than the bed.

Measurement is performed using ITU-R BS.1770-4 loudness metering:

python
def measure_vb_ratio(vocal_path, bed_path):
    vocal_lufs = measure_loudness(vocal_path)
    bed_lufs = measure_loudness(bed_path)
    return vocal_lufs - bed_lufs


3.3.2 Loudness Range

The LRA is a measure of the dynamic range of the audio, computed as the difference between the 95th and 10th percentiles of the short-term loudness distribution:

python
def measure_lra(audio_path):
    st_loudness = measure_short_term_loudness(audio_path, window=3.0)
    return np.percentile(st_loudness, 95) - np.percentile(st_loudness, 10)


For the talk-box instrument, the target LRA is 4 to 8 LU.

3.4 The Boy-Scouts-Agent-Audit (BSAA)

The Boy-Scouts-Agent-Audit (BSAA) is a zero-trust framework for audio provenance. The name derives from the Boy Scouts motto "Be Prepared": the framework ensures that every element of the synthesis pipeline is prepared for audit, with cryptographic evidence of its integrity.

3.4.1 Chain of Custody

The BSAA chain of custody includes the following elements:

1. Input MIDI file. SHA-256 hash of the MIDI file.
2. Master seed. The seed value used for humanisation.
3. Code version. Git commit hash of the synthesis code.
4. Parameter set. JSON file containing all synthesis parameters.
5. Intermediate renders. SHA-256 hashes of each intermediate audio file.
6. Final output. SHA-256 hash of the final WAV file.
7. Timestamp. ISO 8601 timestamp of the synthesis run.
8. Operator. Identifier of the person or system that ran the synthesis.

    with open(log_path) as f:
        log = json.load(f)
    
    errors = []
    
    # Verify MIDI hash
    midi_hash = sha256_file(log['inputs']['midi_file']['path'])
    if midi_hash != log['inputs']['midi_file']['sha256']:
        errors.append("MIDI hash mismatch")
    
    # Verify intermediate hashes
    for intermediate in log['intermediates']:
        hash = sha256_file(intermediate['path'])
        if hash != intermediate['sha256']:
            errors.append(f"Intermediate hash mismatch: {intermediate['stage']}")

    output_hash = sha256_file(log['output']['path'])
    if output_hash != log['output']['sha256']:
        errors.append("Output hash mismatch")
    
    return len(errors) == 0, errors

    lip_reflection: float = -0.9

class KellyLochbaumTract:
    """
    Kelly-Lochbaum digital waveguide model of the vocal tract.
    
    This class implements the discrete-time scattering equations for a
    series of cylindrical tube sections, with reflection coefficients
    determined by the area function.
    """
    
    def __init__(self, params: KLTractParams = None):
        self.params = params or KLTractParams()
        self.num_sections = self.params.num_sections
        
        # State variables: forward and backward travelling waves
        self.forward = np.zeros(self.num_sections + 1)
        self.backward = np.zeros(self.num_sections + 1)
        
        # Reflection coefficients (computed from area function)
        self.reflection_coeffs = np.zeros(self.num_sections)
        
        # Radiation filter state
        self.radiation_prev = 0.0
        
        # Current area function
        self.area_function = None
        
    def set_area_function(self, area_control_points: np.ndarray) -> None:
        """
        Set the area function from 8 control points, interpolating to
        num_sections using log-linear interpolation.
        """
        num_control = len(area_control_points)
        control_indices = np.linspace(0, self.num_sections, num_control)
        
        # Log-linear interpolation
        log_areas = np.log(area_control_points)
        section_indices = np.arange(self.num_sections + 1)
        log_interpolated = np.interp(section_indices, control_indices, log_areas)
        self.area_function = np.exp(log_interpolated)
        
        # Compute reflection coefficients
        for i in range(self.num_sections):
            A1 = self.area_function[i]
            A2 = self.area_function[i + 1]
            self.reflection_coeffs[i] = (A1 - A2) / (A1 + A2)
    
    def set_vowel(self, vowel: str) -> None:
        """Set the area function to a predefined vowel."""
        if vowel not in VOWEL_AREA_FUNCTIONS:
            raise ValueError(f"Unknown vowel: {vowel}")
        self.set_area_function(VOWEL_AREA_FUNCTIONS[vowel])
    
    def process_sample(self, glottal_input: float) -> float:
        """
        Process a single sample through the waveguide model.
        
        Args:
            glottal_input: Volume velocity input at the glottis.
            
        Returns:
            Radiated pressure at the lips.
        """
        # Glottal boundary condition
        self.forward[0] = glottal_input + self.params.glottal_reflection * self.backward[0]
        
        # Scattering at each junction
        for i in range(self.num_sections):
            r = self.reflection_coeffs[i]
            
            # New forward wave at section i+1
            new_forward = (1 + r) * self.forward[i] + r * self.backward[i + 1]
            
            # New backward wave at section i
            new_backward = r * self.forward[i] + (1 - r) * self.backward[i + 1]
            
            # Update state (in-place to avoid allocation)
            self.forward[i + 1] = new_forward
            self.backward[i] = new_backward
        
        # Lip boundary condition
        self.backward[self.num_sections] = self.params.lip_reflection * self.forward[self.num_sections]
        
        # Output pressure at lips
        pressure = self.forward[self.num_sections] + self.backward[self.num_sections]

        radiated = pressure - self.params.radiation_alpha * self.radiation_prev
        self.radiation_prev = pressure

class KarplusStrongString:
    """
    Karplus-Strong digital waveguide string model.
    
    This implements the classic KS algorithm with a two-point averaging
    loop filter and a noise-burst excitation.
    """
    
    def __init__(self, frequency: float, sample_rate: int, 
                 decay_seconds: float = 2.0, brightness: float = 0.5):
        self.sample_rate = sample_rate
        self.frequency = frequency
        self.decay_seconds = decay_seconds
        self.brightness = brightness
        
        # Delay line length (accounting for loop filter phase delay)
        self.delay_length = int(sample_rate / frequency - 0.5)
        
        # Loop gain for target decay time
        self.loop_gain = 10 ** (-3.0 / (decay_seconds * frequency))
        
        # Delay line state
        self.delay_line = np.zeros(self.delay_length)
        self.write_index = 0
        
        # Excitation filter state
        self.excitation_prev = 0.0
        
        # Flag: whether the string has been plucked
        self.plucked = False
        
    def pluck(self, rng: np.random.Generator = None) -> None:
        """
        Excite the string with a noise burst.
        
        The noise burst is shaped by a one-pole lowpass filter whose
        cutoff is determined by the brightness parameter.
        """
        if rng is None:
            rng = np.random.default_rng()
        
        # Generate noise burst
        noise = rng.standard_normal(self.delay_length)
        
        # Apply brightness filter (one-pole lowpass)
        # brightness=0 -> dark, brightness=1 -> bright
        alpha = 0.9 - 0.8 * self.brightness
        filtered = np.zeros_like(noise)
        for i in range(len(noise)):
            filtered[i] = (1 - alpha) * noise[i] + alpha * self.excitation_prev
            self.excitation_prev = filtered[i]
        
        # Load into delay line
        self.delay_line = filtered
        self.plucked = True
    
    def process_sample(self) -> float:
        """Process a single sample through the string model."""
        if not self.plucked:
            return 0.0
        
        # Read from delay line
        output = self.delay_line[self.write_index]
        
        # Two-point averaging loop filter
        next_index = (self.write_index + 1) % self.delay_length
        filtered = 0.5 * (output + self.delay_line[next_index])
        
        # Write back with loop gain
        self.delay_line[self.write_index] = self.loop_gain * filtered
        
        # Advance write index
        self.write_index = next_index
        
        return output
    
    def process_block(self, num_samples: int) -> np.ndarray:
        """Process a block of samples."""
        output = np.zeros(num_samples)
        for n in range(num_samples):
            output[n] = self.process_sample()
        return output

def karplus_strong_pluck(
    frequency: float,
    sample_rate: int,
    duration: float,
    decay_time: float = 2.0,
    brightness: float = 0.5,
    rng: Optional[np.random.Generator] = None
) -> np.ndarray:
    """
    Generate a Karplus-Strong plucked string sound.
    
    Args:
        frequency: Fundamental frequency in Hz.
        sample_rate: Sample rate in Hz.
        duration: Duration in seconds.
        decay_time: T60 decay time in seconds.
        brightness: Brightness parameter (0=dark, 1=bright).
        rng: Random number generator (for reproducibility).
        
    Returns:
        Audio buffer as numpy array.
    """
    if rng is None:
        rng = np.random.default_rng()
    
    # Delay line length
    delay_length = int(sample_rate / frequency - 0.5)
    if delay_length < 1:
        raise ValueError(f"Frequency {frequency} Hz too high for sample rate {sample_rate} Hz")
    
    # Loop gain
    loop_gain = 10 ** (-3.0 / (decay_time * frequency))
    
    # Number of samples
    num_samples = int(duration * sample_rate)
    
    # Initialize delay line with noise
    noise = rng.standard_normal(delay_length)
    
    # Apply brightness filter
    alpha = 0.9 - 0.8 * brightness
    filtered = np.zeros(delay_length)
    prev = 0.0
    for i in range(delay_length):
        filtered[i] = (1 - alpha) * noise[i] + alpha * prev
        prev = filtered[i]
    
    # Generate output
    output = np.zeros(num_samples)
    delay_line = filtered.copy()
    write_index = 0
    
    for n in range(num_samples):
        # Read from delay line
        output[n] = delay_line[write_index]
        
        # Two-point averaging filter
        next_index = (write_index + 1) % delay_length
        filtered_sample = 0.5 * (output[n] + delay_line[next_index])
        
        # Write back with loop gain
        delay_line[write_index] = loop_gain * filtered_sample
        
        # Advance
        write_index = next_index
    
    return output

def little_sqrt_diagnose(vocal_path, bed_path, output_path):
    """
    Run Little sQrt placement diagnosis.
    
    Returns a JSON report with V/B ratio and LRA measurements.
    """
    import json
    import pyloudnorm as pyln
    import soundfile as sf
    import numpy as np
    
    # Load audio
    vocal, rate_v = sf.read(vocal_path)
    bed, rate_b = sf.read(bed_path)
    
    # Ensure mono
    if len(vocal.shape) > 1:
        vocal = vocal.mean(axis=1)
    if len(bed.shape) > 1:
        bed = bed.mean(axis=1)
    
    # Measure loudness (ITU-R BS.1770-4)
    meter = pyln.Meter(rate_v)
    vocal_lufs = meter.integrated_loudness(vocal)
    bed_lufs = meter.integrated_loudness(bed)
    
    # V/B ratio
    vb_ratio = vocal_lufs - bed_lufs
    
    # LRA (using pyloudnorm's implementation)
    # Note: pyloudnorm does not have a built-in LRA function;
    # this is a simplified implementation
    block_size = int(3.0 * rate_v)  # 3-second blocks
    num_blocks = len(vocal) // block_size
    st_loudness = []
    for i in range(num_blocks):
        block = vocal[i*block_size:(i+1)*block_size]
        st_loudness.append(meter.integrated_loudness(block))
    
    lra = np.percentile(st_loudness, 95) - np.percentile(st_loudness, 10)
    
    # Generate report
    report = {
        'version': '2.0.2',
        'vocal_lufs': vocal_lufs,
        'bed_lufs': bed_lufs,
        'vb_ratio_lu': vb_ratio,
        'vb_target': [15, 20],
        'vb_pass': 15 <= vb_ratio <= 20,
        'lra_lu': lra,
        'lra_target': [4, 8],
        'lra_pass': 4 <= lra <= 8
    }
    
    with open(output_path, 'w') as f:
        json.dump(report, f, indent=2)
    
    return report
